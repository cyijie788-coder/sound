# 奕起聊车偏好与适用范围

依据用户在 RS7、M4 制作过程中的要求整理，2026-11-14。后续当前指令和工程 AGENTS.md 优先。

## 持续适用

- 成片质量最重要，工作量和催促不能成为漏检的理由。用户希望可直接提供素材与口播，助手完成整理、制作和验收。
- 保留已批准的文案、人声音色和用户已删除的词句；局部请求不能变成整段重写。技术代号和数字以核实后的台词为准。
- 时间轴、预览、输出均为 60 fps。选用经核对的原生 4K 或更高画面来源，输出不必强制 4K。裁切、放大、AI 生成的实际像素与例外必须记录并说明。
- 高质量有水印素材可选；取得干净来源或清理水印后，检查车身细节和修补区域的运动连续性。记录来源、许可和必要署名，不把水印处理等同于授权。
- 以视频为主，素材与台词匹配，避免重复同一段原片。是否必须避免重复同一台车按当前要求确认，不能把“同一型号”误判成“同一台实车”。
- 重点词有层级、粗体、有力度；字幕透明底，手机尺寸可读。前 30 秒以强画面、清楚悬念、语义落点吸引注意；不承诺实际留存率。
- “说一个字出一个字”指逐字时间对齐和平滑出现，不能整段突然跳出。保留字的位置，后续字出现时前面不抖动、不重新排版。
- 人声干净、贴近，BGM 有存在感但不盖人声；现成音效对应动作或词语。不要音乐/音效生成器。
- 无意短镜头、闪屏、停顿要主动排查；技术检测通过不代表视觉通过。
- 账号为“奕起聊车”，不是“一起聊车”。弱品牌只显示一处；位置按当前指令和安全区配置。
- 样板默认只在对话中展示，不往桌面堆放；正式交付需要实际保存并核对。沟通简短，报真实阶段和可信时间。

## 单片设置示例，不自动推广

| 设置 | 对应案例 | 后续如何处理 |
| --- | --- | --- |
| 横版 16:9、1080p60 | 当前 RS7、M4 系列 | 接续当前工程保持；新项目读明确画幅，未指定读 AGENTS 的默认画布 |
| PNG 约 1.5 秒、不得超过 2.5 秒、图片之间穿插视频 | RS7 | 用户要求沿用时使用，不套到参数动画或所有实拍镜头 |
| 全部主车为改装 M4，优先绿色 | M4 | 只用于 M4 选材，不影响未来车型 |
| 片头打趣配指定参考 BGM；前约 19 秒逐字大字幕、不重复底部字幕 | M4 | 提速后用实际台词区间定位，不能硬编码永远 19 秒 |
| S58 到 3.5 秒一整段参数动效、M4 PNG 替换卡通车 | M4 | 新车型重新核对参数与图像；演示标注非实测 |
| 语速提高 6%、BGM 先加 2 dB 再避让 | M4 V4 | 是一次调整量，不是以后默认增益或固定速度 |
| 角标移到画布最左上角 | M4 明确覆盖默认安全区位置 | 仅接续本片保持；新片仍依项目安全区 |
| 封面 16:9、4:3、3:4，车头均朝右 | 本次 M4 封面 | 作为沿用该封面风格时的配置；不擅自每次生成三套 |
| 约 3 秒快速驶远、引擎渐小、灯光/画面淡出 | 后期认可的结尾方向 | 用户曾先选无声后改为引擎声；以最新要求为准，不同时执行冲突版本 |
