# 视频返修与验收清单

与[制作流程](README.md)和[项目规则](../AGENTS.md)配合使用。以下项目按当前任务适用情况检查；检查结果以实际制作与导出文件为准。

## 制作前

- [ ] 原口播、素材、已有SRT和必须使用的内容已对应。
- [ ] 当前画布比例、发布平台、输出尺寸、60fps时间轴及安全区已明确。
- [ ] 每条参考的用途已记录，开场、动效、音乐和构图参考分别对应。
- [ ] 真实分辨率、车型代际、原厂或改装版本已核对，未达标素材有记录。
- [ ] 原片可用区间、内部切点和已用区间已检查。
- [ ] 画面水印位置已标记，所选素材以质量优先。
- [ ] 素材、BGM、字体和音效来源及许可要求已记录。
- [ ] 需要比较的样板仅作对话预览。

## 剪辑与声音后期

- [ ] 台词与口播速度保持当次要求，字幕按语义和停顿切分。
- [ ] 关键数据对应正确车型版本，画面表达与台词一致。
- [ ] 重复车辆、重复原片区间、图片时长和相邻图片符合本片要求。
- [ ] 重点词、关键数字、字幕和账号角标保持统一层级，互相避让。
- [ ] 动效起始、最大过冲、收稳、阅读和切镜前画面均已检查。
- [ ] 水印清理区域无明显修补痕迹、闪烁、拖影及主体细节损伤。
- [ ] 人声、BGM和音效分轨保留，音效对应动作或话语。
- [ ] 音乐具体版本、截取范围和插段时长与要求一致。
- [ ] 原有录音经过适当处理，人声清楚，声音尾部和切点自然。

## 每轮返修记录

| 项目 | 记录内容 |
| --- | --- |
| 基准版本 | 明确用户正在看的文件和版本 |
| 反馈位置 | 基准版时间点及对应台词或镜头 |
| 修改目标 | 需要增加、移除、替换或调整的内容 |
| 影响范围 | 关联视频、字幕、配音、BGM、音效和片尾 |
| 时间变化 | 插入或删除时长，旧时间与新时间的对应关系 |
| 验收结果 | 实际检查的片段、通过项与未解决项 |

- [ ] 新增或删减内容后，所有后续轨道与SRT已重新对齐。
- [ ] 相关镜头前后均已检查，没有上一镜残留帧或意外短片段。
- [ ] 出现异常时检查了原素材和取帧边界，并复核实际导出结果。
- [ ] 自动检测到的静止、高变化或短切片段已经结合实际画面判断。

## 实际导出文件验收

- [ ] 完整解码到文件末尾，尺寸、时长、实际帧率与时间轴一致。
- [ ] 时间戳连续；原生24fps或30fps素材在60fps时间轴上的正常重复帧与异常停顿分别判断。
- [ ] 用户反馈的卡点和闪屏位置已修正，新增切点也已检查。
- [ ] 字幕、重点词与口播同步，插段没有造成轨道错位。
- [ ] 动效和关键文字保持在当前安全区，手机尺寸预览可读。
- [ ] 实际成片中的素材水印已清理，账号角标符合当前要求。
- [ ] 人声清楚，BGM和音效不遮盖台词，响度与峰值检查通过。
- [ ] 音效落点、尾音、音乐衔接及片尾的淡入淡出符合要求。
- [ ] 正式封面已核对标题、裁切和实际像素尺寸。
- [ ] 实际试听、手机尺寸预览和手机设备播放分别如实记录。

## 正式交付

- [ ] 文件名与版本明确，旧版按任务要求保留。
- [ ] 视频及所需SRT、正式封面保存到指定位置，样板不混入交付。
- [ ] 复制文件的大小或校验值一致，交付路径实际存在。
- [ ] 正式文件可打开，交付入口指向正确版本。
- [ ] 未解决的质量问题和未达标项已明确告知。
